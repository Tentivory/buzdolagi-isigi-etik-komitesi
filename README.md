# Buzdolagi Isigi Etik Komitesi

## Resmi Uyari

Bu depo, gece yarisi buzdolagini acmadan once **ulusal etik kurul** onayini zorunlu kilan tarihi bir reformdur. Reform degildir. Sadece oyle duruyor.

Buzdolagi isigi, modern toplumun en az tartisilan kamu aydinlatmasidir. Bu proje o tartismayi baslatmaz; bitmis gibi yazar.

## Kurulus Amaci

1. Acikligi oyle resmi gostermek ki insan sut icmekten vazgecsin.
2. Calisan bir Python betigi ile sahte tutanak uretmek.
3. Bilimi degil, tutanagin fontunu ciddiye almak.

## Kurulum

python3 komite.py
